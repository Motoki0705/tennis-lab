## 評価条件

打球とバウンドは `single_object` の固定val・test各128ラリーを使用した。
ネット接触はBLCSの衝突記録を使い、メッシュに当たる球、白帯に当たって進行方向のY成分を保つ球、
接触せず越える球を各32軌跡ずつ、別seedでval・testに生成した。
いずれも60 fpsで、物理記録のイベントを直後の出力frameに割り当てた。
同一軌跡・同一種別で±3 frame以内を1対1で突き合わせた。時刻誤差は対応したイベントのみの平均絶対誤差。
合成データの採点はボールのみで行った。

欠測条件では物理イベントの約半数に対して前後それぞれ3〜10 frameの長さを抽選し、
中心を含む連続区間を隠した。現行の欠測生成器の規則で前後幅を異ならせ、ほかの観測は独立に1%を隠した。
有効点に座標軸あたり標準偏差1.5 cmのガウス雑音を加えた。
testではラリーの6,756 / 54,019 frame、ネット評価の819 / 3,456 frameが欠測した。

## 閾値の決定

欠測・雑音付きvalの13設定で3クラスのmacro F1を比較した。
初期設定の0.623に対して選択設定は0.844だった。調整で採用したのは欠測上限0.34 s、
両側からの外挿位置の許容差0.55 m、ボールのみの打球で水平速度変化7.5 m/s、
打球後水平速度4.5 m/s、速度増分による判定6.5 m/s。
速度計測は0.05 s、バウンドの上限高0.27 mと両側鉛直速度0.75 m/s、
ネット面の許容距離0.36 m、Y速度保持率の上限0.55を使った。
選手近傍の条件は手首1.15 m、root 1.85 mの幾何的な許容距離に基づく。
各設定の全閾値と指標を保存した。 [指標と閾値](../../runs/run-i2568-rule-ball-events-20261126/metrics.json)
