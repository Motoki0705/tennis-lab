## 修正判断

`TopdownHeatmapSimpleHead.forward`は最終線形Conv2dを返し、
`kp2d_utils._get_max_preds`はその最大値をscoreとして返す。sigmoid/softmaxが無いため、
`FeatureExtractor`と`DetectionFeatures`で要求した`0 <= pose score <= 1`が誤り。
pose呼出しは変えず、生heatmap peakを有限の実数として保持する。clip/sigmoidや異常rowのスキップを入れない。
非有限値はframe・検出row・joint・channel・値を記録して停止する。
archive v2で契約を明示し、v1は自動変換せず拒否する。encoder promptにも同じ生scoreを渡す。

実入力の回帰テストは抽出・prompt・保存/読戻しで1超のscoreを保持することを検査し、
NaN/±infはencoder呼出し前に停止することを別途検査する。
次は新しいrun IDで同じ120frame×3cameraのGPU smokeを実行する。
これは方式の精度比較ではなく、遠側検出の方針確定までは最終追跡比較を行わない。
