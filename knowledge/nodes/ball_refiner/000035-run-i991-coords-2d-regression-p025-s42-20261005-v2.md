共有BLCSデータ1,280ラリーを使い、2Dの回帰を4,000更新した。学習のイベント選択率は25%、評価は全15条件共通の50%・seed20991で固定し、train/val/testはラリー単位で分離した。入力は座標と欠損maskだけで、観測区間を含む全frameの1本の軌道を推論した。

validation RMSE=17.0434 pxのstep 4000を選び、そのcheckpointでtestを評価した。test RMSEは全体16.7661、欠損33.8868、観測11.4039、イベント±5frame29.5159 px。実際のframe欠損率は14.83%である。線形補間対照の全体RMSEは74.2021 pxで、これは観測frameのノイズをそのまま保持する対照。

共通データ・固定劣化による1 seedの合成比較であり、実動画やGAN一般の有効性を示すものではない。視点は両baseline後方のfence上から選び、cleanな全軌道が画面内に入る条件に限定した。初回生成の画面外極値を修正する際にも3D真値・イベント・時刻・splitは変えていない。各方式・欠損条件の比較とvalidationによる候補選定は、このrunを含むgroup nodeで行う。

学習中peak allocatedは192.8 MiB、学習時間は216.0秒。共有queueのhalf枠2本同時実行のため、このrunの推論時間は単独GPU速度としては用いず、比較report jobで改めて測定する。TensorBoardのtrain/reconstructionとval/rmseは別の尺度である。共通kg_curvesがこのtagを扱わないため、保存JSONLとvalidation JSONから別軸の学習曲線を作成して添付した。

単独GPUでのrefiner推論は128frameあたり中央値3.932 ms。model load・転送・三角測量を含まない。
