## 欠損と不確実性

元clip時間軸の固定人工gap内でobserved教師がある2,493frameでは、
位置NLLは−3.00312 uv密度単位 / 11.54023 source px密度単位、
mean/median/p95は112.934 / 76.613 / 321.866px、20px recallは4.21%。
観測条件の位置NLLは−4.38014 / 10.16321。
GaussianはR²上で、NLLの負値は連続密度として正常。unit間はlog((W−1)(H−1))で変換する。

全混合分散のtrace平均は観測14,639px²、gap 20,313px²。
これは異なるframe母数の集計で、gap長に応じた適切な較正やcoverageを示したものではない。
存在BCEは観測0.00793、gap 0.01008だが、Meiji評価には確定負例がなく、不存在の較正は判断できない。
人工gapは検出証拠を消した条件で、RGB遮蔽・実amodal GTではない。
