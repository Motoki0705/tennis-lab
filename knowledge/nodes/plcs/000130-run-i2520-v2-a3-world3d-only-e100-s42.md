## 考察 / Findings

### 実験目的と設定
- M1（`run-i2520-v2-m1-mono-gvhmr-htd-e100-s42`）から canonical 姿勢・関節角/捻れ角/体幹ひねり損失をすべて無効化（`canonical_pose_weight=0.0, joint_angle_weight=0.0, torsion_angle_weight=0.0, torso_twist_weight=0.0`）し、World 3D骨格＋位置＋再投影＋骨長＋Stage A PVA損失のみで学習したアブレーション（**A3**）。なお、逆方向（`world_kp_3d_weight=0.0`）は `plcs_monocular_gvhmr` の設定契約（`SemanticConfigurationError`）で禁止されているため、本条件で3D世界座標直接監視とcanonical/角度正則化の役割分離を検証した。
- 100エポック無停止完走（`torsion_angle` 共線クラッシュ 0 回）。

### 観測（test split および横断評価）
- `single_object_mixed` test split（`trainer.test`, `last.ckpt`）:
  - `position_error_m = 1.1842 m`（`position_accuracy_0.5m = 36.33%`）
  - `angular_error_deg = 13.06°`（`angle_accuracy_15deg = 66.94%`）
  - `canonical_mpjpe_m = 0.2728 m`（`canonical_pck_0.1m = 5.49%`）
- 横断評価（`run-i2520-cross-eval-and-htd-stage-b`）における M1 との比較:
  - 合成3 split の方位角は単眼単独モデル中ベスト（`fixed 20.19°`, `broadcast 11.72°`, `mixed 13.59°`）であり、骨長分散（`14.4〜16.7 mm`）もやや低い。
  - 一方で、合成3 split すべてで **位置誤差（`1.895 / 2.194 / 1.030 m` vs M1 `1.591 / 2.035 / 0.940 m`）と関節形状精度 `PA-MPJPE`（`0.131 / 0.143 / 0.107 m` vs M1 `0.122 / 0.096 / 0.092 m`）が悪化** した。
  - 実動画 `meiji_4cam` でも、同一視点再投影は締まる（中央値 `3.92 px` vs M1 `4.80 px`）一方、**他視点LOVO（`705.8 px` vs `612.6 px`）・カメラ間3D整合（`6.70 m` vs `5.83 m`）・vs DLT MPJPE（`4.263 m` vs `3.718 m`）がすべて悪化** した。

### 考察と限界
- canonical姿勢＋骨格角度監視を外すと、モデルが同一視点の2D再投影合わせへ寄りやすく、3D骨格構造（PA-MPJPE）と未見実カメラでの奥行き汎化（LOVO・vs DLT）が劣化する。一方、`torsion_angle` による学習クラッシュは完全に消失した。
- 実務的には、canonical姿勢監視は保持しつつ、`torsion_angle` の共線フレームのみ安全マスク化する設計（後続PR）が望ましい。
- `summary_impact: none` の理由: アブレーション単体記録であり、全体判断は `group-i2520-monocular-gvhmr-htd` で統合する。
