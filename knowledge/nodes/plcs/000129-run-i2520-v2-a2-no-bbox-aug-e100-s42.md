## 考察 / Findings

### 実験目的と設定
- M1（`run-i2520-v2-m1-mono-gvhmr-htd-e100-s42`）から学習時の **合成bboxゆらぎ増強のみを無効化**（`data.augmentation.monocular_bbox.enabled=false`）したアブレーション（**A2**）。100エポック完走（best `plcs-epoch=59.ckpt`、M1のbest epochと完全一致）。

### 観測（test split および横断評価）
- `single_object_mixed` test split（`trainer.test`, best `plcs-epoch=59.ckpt`）:
  - `position_error_m = 1.3145 m`（`position_accuracy_0.5m = 31.48%`）
  - `angular_error_deg = 15.88°`（`angle_accuracy_15deg = 56.90%`）
  - `canonical_mpjpe_m = 0.2407 m`（`canonical_pck_0.1m = 11.46%`）
- 同一エポック（Epoch 59）の M1 との横断比較（`run-i2520-cross-eval-and-htd-stage-b`）:
  - 合成 `fixed`: 位置誤差 `1.776 m`（M1 `1.591 m` 比 +11.6%）、方位角 `36.04°`（M1 `27.30°` 比 +8.7°）、`MPJAE = 116.82 m/s²`（+29.1%）、`jerk = 18,342 m/s³`（**+27.4%悪化**）。
  - 合成 `broadcast`: 位置誤差 `2.130 m`（M1 `2.035 m` 比 +4.7%）、`MPJAE = 210.21 m/s²`（+23.4%）、`jerk = 33,672 m/s³`（**+23.2%悪化**）。
  - 合成 `mixed`: 位置誤差 `0.949 m`（M1 `0.940 m`）、`MPJAE = 156.73 m/s²`（+32.7%）、`jerk = 28,333 m/s³`（**+38.4%悪化**）。
  - 実動画 `meiji_4cam`: `LOVO = 684.7 px`（M1 `612.6 px` 比 **+11.8%悪化**）、`vs DLT MPJPE = 3.832 m`（M1 `3.718 m` 比 +3.1%）、`jerk = 226,325 m/s³`（M1 `163,336 m/s³` 比 **+38.6%悪化**）。

### 考察と限界
- 同一エポック（Epoch 59）同士の公平比較において、合成bboxゆらぎ増強を切ると **加速度誤差（MPJAE）と高周波ジッタ（jerk）が合成・実動画の全splitで +23%〜+39% 悪化** し、実動画の検出器bboxジッタ（DINO + StrongSORT++）に対する耐性が明確に低下した。
- 一方でクリーン合成時の静的 `PA-MPJPE`（`mixed: 0.0875 m` vs M1 `0.0915 m`）はわずかに改善しており、検出ゆらぎ増強が「クリーンbboxへの過適合」を防ぎ時系列ロバスト性とトレードオフにあることを示している。
- `summary_impact: none` の理由: アブレーション単体記録であり、全体判断は `group-i2520-monocular-gvhmr-htd` で統合する。
