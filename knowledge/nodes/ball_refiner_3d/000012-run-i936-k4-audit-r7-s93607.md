## 方法と誤差推定

正則A/単眼rayは維持。複数視点の非正則productではmodeに合わせたray座標を
`mode + L tan(πu/2)`で全域へ写し、5/7点Gauss–Legendre則でmass/1次/2次momentを積分する。
差の大きいcellを8分割し、未分割cellの質量も残す。有限world箱の切断はない。
全Hessianが非SPDの3成分には、明示したchart方針として白色化画素/log-depthの単位軸を使い、
`metric_is_local_hessian=false`を記録する。返す共分散のjitter修復ではない。

外側予算は角度次数12/20/32/48/64、適応cell cap64/128/256/512/1024。
内側の選択目標は0.02/0.01/0.003/0.001/0.0003。
外側のNLL0.05nat、全成分evidence0.05nat、mean0.02m、covariance relative0.05は変更せず、
最低3段階。各段階で実際に追加細分化し、GTは判定にもchartにも使わない。

| 成分方式 | 使用数（全38,875成分） | 誤差推定・限界 |
|---|---:|---|
| prior | 311 | 指定Gaussianの解析moment/evidence |
| laplace | 26,072 | 従来Aの局所近似。数値段階間では不変で、近似誤差の上界はない |
| 単眼ray | 3,732 | 正depthを解析積分、角度Hermiteの隣接次数差 |
| adaptive_ray:boundary_laplace_tail | 6,355 | 外側隣接差＋補助の5/7則差 |
| adaptive_ray:camera_boundary | 2,330 | 同上。全cameraの正depth制約を保持 |
| adaptive_ray:iteration_budget | 75 | 同上。成分削除・prior置換をしない |

埋め込み差の合計/質量はp50=0.000735、p95=0.003733、最大1.129。
これはpriorで白色化した未正規化momentの補助指標で、mやnatの誤差上界ではない。
内側目標未達は877成分。**外側を通過した220frameのうち139frameにも内側目標未達が残る**。
両方を通過したのは81frameに留まる。外側の70.74%を高精度積分の保証と解釈しない。
この弱さも既定変更を見送る理由である。局所chartが共通して見落とすmode、AのLaplace誤差、
Gaussianへのmoment要約誤差は保証されない。

探索4件では3/5点則が保守的な内側目標を満たせず高コストだった。
5/7則でも内側目標を外側の追加必須条件にすると費用が増えることを確認した。
その探索結果と5/7版source archiveをbundleに残した。監査本体は指定された元の外側判定を維持する。
探索結果を全標本の率へ混ぜていない。
