## 1. 実験概要と統制条件

GVHMR型の Early Fusion（カメラ内外パラメータ + 2D COCO17 + CLIFF 合成bbox、HMR2特徴なし、`dim=512, 12 layers, 8 heads, RoPE`）と HTD-Refine 拡張（Stage A: `PVA-Heads` による速度・加速度・接地確率予測、Stage B: `PLCSHTDRefiner` による軌道最適化）を PLCS に導入し、以下の統制条件で段階的アブレーションと実動画評価を行った。

- **学習データ**: `plcs/single_object_mixed`（fixed + broadcast 混在合成シーン）
- **学習予算（全モデル共通）**: `max_epochs=100`, `warmup_steps=500`, 実効バッチサイズ `16`, `seed=42`, `bf16-mixed`, `compile=false`（RTX 5060 Ti 16GB）
- **評価データ**:
  1. 合成 `single_object`（fixed固定カメラ, 100シーン / 66,927フレーム）
  2. 合成 `single_object_broadcast_eval`（broadcast俯瞰・望遠, 100シーン / 70,613フレーム）
  3. 合成 `single_object_mixed`（混在, 100シーン / 65,346フレーム）
  4. 実動画 `meiji_4cam/multiview-player-evaluation-v1`（ピン留め6クリップ, `manifest_sha256=3dc49651...`, 50,297選手視点フレーム, 4カメラDLT欠損392フレーム; HMR2/SMPL-X不使用）
- **オフライン評価環境**: CPU 4スレッド（`OMP_NUM_THREADS=4`, 長系列は 2048フレーム・128オーバーラップで分割推論）。再現スクリプトと全JSONは [cross-eval bundle](../runs/run-i2520-cross-eval-and-htd-stage-b/repro.sh) に保存。

## 4. 発見した故障モードと後続コード修正候補

1. **既定損失設定によるCLIFF深度崩壊・初期退化（高優先）**:
   - 現行 `src/tasks/plcs/configs/loss/monocular_htd.yaml` の `kinematic_acceleration_consistency_weight=0.1` は、学習時 bbox スケール増強（`13.95%/frame`）と `fps² (900〜3600)` の掛け算で `8,915`（総損失の `93.6%`）に達し、CLIFF `pred_cam` の `tz → 0` 崩壊（`25.3 m`）を確実に引き起こす。
   - `monocular_base.yaml` / `monocular_htd.yaml` の `rotation_weight=1.0, angle_weight=0.5` も初期エポックの股関節退化を誘発する。
   - 対策: v2 実証済みの損失バランス（`kinematic_*_consistency_weight=0.0`, `rotation_weight=0.02`, `angle_weight=0.0`）を既定configへ反映する。
2. **`torsion_angle` 共線フレームによる学習停止（中優先）**:
   - `src/tasks/plcs/training/losses.py:271` の `pred.require_valid` が、身体的に正常な完全伸展腕（180°共線）を含む1フレームで `ValueError` を送出し学習を止めた（`M1` Ep 68、`A1` Ep 55）。
   - 対策: 予測骨格の非退化チェック（NaN/Inf・ゼロ骨長）と3点共線による捻れ角未定義を分離し、共線フレームはGT側と同様にマスク除外して学習継続する。
3. **未見実スタジアムカメラでの単眼光線深度シフト（研究課題）**:
   - `M2-SV` は同一視点再投影中央値 `1.27 px`・PA-MPJPE `11.1 cm` を達成しながら、光線方向深度に `3.27 m`（中央値）のオフセットが残る。`M2-MV` で多視点制約を入れると `1.04 m` へ急減したため、単眼時の課題は「合成カメラ焦点距離・仰角分布と実スタジアム校正分布のドメイン差」および「接地足首のコート平面（`z=0`）光線交点による初期深度アンカー未活用」にある（仮説）。

## 6. 次の実験候補
1. 上記2件のバグ修正（既定lossバランス更新＋`torsion_angle` 共線マスク化）後、`M0` / `M1` の複数seed（3 seed × 100エポック完走）での再現確認。
2. 実スタジアム相当の広角・高仰角・長距離カメラ分布を合成学習データへ追加し、さらに足接地時のコート平面（`z=0`）光線交点制約を Stage B 初期深度アンカーとして組み込むことによる `meiji_4cam` 単眼深度誤差（`3.70 m → <1.0 m` 目標）の検証。
