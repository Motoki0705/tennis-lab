# Papers — 関連研究

関連研究のPDFと読解メモを一元管理する。タスク別にコピーせず、論文metadataの`tasks`とノードの`papers`で結合する。

- 保存形式・命名: [knowledge仕様](../README.md#papersの仕様)
- 登録・出典確認・summary更新: [knowledge-control skill](../../.agents/skills/knowledge-control/SKILL.md#record-or-correct-evidence)
- [Web UI](../webui/README.md) のPapersタブで論文と参照実験を相互に辿る。
