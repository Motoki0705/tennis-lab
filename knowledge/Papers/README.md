# Papers — 関連研究

人間が研究に必要と判断した関連研究の書誌情報・一次資料URL・要約・採録理由・読解メモを文書のみで管理する。タスク別にコピーせず、論文metadataの`tasks`とノードの`papers`で結合する。

- 保存形式・命名: [knowledge仕様](../README.md#papersの仕様)
- 登録・出典確認: [knowledge-control skill](../../.agents/skills/knowledge-control/SKILL.md#record-or-correct-evidence)
- [Web UI](../webui/README.md) のPapersタブで論文と参照実験を相互に辿る。
