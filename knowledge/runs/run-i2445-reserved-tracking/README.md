# Meiji 3camの予約未見3本を固定設定で採点

Meiji 3camの人手ラベルで、選手枠統合を含む3D追跡・選別を一度採点した。予約3本・9視点・38,421行のViTPose成果物を #2444 から読み、完了記録のSHA-256 `4966ade3bec4fea665a2613f1e9255117de70f1f2a58fa12aa7ccef0ecbe7270` と照合した。開発用と同じ設定と採点器のdigest、入力計画、校正補完とラベルのSHA-256を採点開始記録と結果で確認した。 [#2444の固定入力](../run-multiview-pose-link-recall-20261124/README.md#予約した未見3-clip)・[Dの固定設定](../run-i2445-player-slot-integration/reserved-protocol.json)

## 選別したIDの射影採点

| 対象 | 元フレーム | IDF1 | Switch | Fragment | 選別precision | 選別recall |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 開発用4本 | 3,497 | 84.50% | 0 | 387 | 99.95% | 73.18% |
| 予約未見3本 | 3,708 | 80.42% | 0 | 546 | 99.99% (14,788/14,790) | 67.25% (14,788/21,989) |

全3本で両サイド1人ずつ選別した。開発用4本に対し、全3本のIDF1は4.08ポイント、recallは5.93ポイント低かった。校正補完を除く2本ではそれぞれ0.52ポイント、0.75ポイント高かった。Fragmentは参照選手の1,000単位あたり開発用18.82、全3本24.83、補完を除く2本30.04件。001/003単独のIDF1は73.84%、recallは58.54%で、補完を除く集計は異なるクリップ集合の結果である。未照合の選別予測は全3本23件、補完を除く2本19件。 [各clip・各カメラの指標と分母](meiji3.json)・[開発用データの指標](../run-i2445-player-slot-integration/meiji3.json)

選別前の全IDを選手ラベル上で採点した射影IDF1・switch・fragmentは、開発用77.97%・737・182、予約未見3本71.25%・1,034・331、補完を除く2本78.28%・558・225だった。元の支持カメラのDINO行へIDを転記する照合では、選別後の全3本はIDF1 80.27%・switch 0・fragment 527・precision 99.99%・recall 67.04%、2本は84.59%・0・366・100.00%・73.29%だった。両集計とも補間した骨格は採点対象外である。 [支持行を含む全指標](meiji3.json)
