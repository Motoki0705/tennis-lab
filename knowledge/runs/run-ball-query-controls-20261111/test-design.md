# Test design (#1899)

- Protect DPT T32 -> fresh query T32/T64 encoder-only transfer with independent query dimensions/heads, identical named AdamW moments, shared pack occurrences, and explicit stage LR offsets. Reject changed encoder topology and non-pretrain parents. Same-query later stages still require an identical topology.
- Reuse `test_sequential_temporal_training.py` and `test_mhc_query.py` for legacy inheritance, real mHC numerical/gradient contracts, and stage schedules. Add three CPU integration cases for the new combinations; use tiny real CNNs, 128-frame packs and three updates per stage. One interrupted first stage must match its uninterrupted model/optimizer/RNG/sample state exactly. Test first-stage T64 query initialization against the T32 route with seed42, including final RNG, rather than checking configuration fields only.
- Test controller fail-closed prerequisite gates, snapshot selection, comparison identity mismatch, exact per-frame GT identity, and campaign LR boundaries. Use temporary files and real snapshot publication/restore through a local rclone alias; no GPU training mocks as proof of numerical stability.
- Production checks: compare initialization to the historical runner in an independent process; preserve all 128-frame sample order and augmentation hashes; inspect real freeze/unfreeze LR rows; verify checkpoint readback from Drive after >600 updates. GPU tests use the shared queue exclusively. Test budgets are never used for the production plan.
