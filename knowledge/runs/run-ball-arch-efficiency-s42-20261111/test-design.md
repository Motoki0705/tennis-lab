# Verification design

- Port: reuse the MDD unit/model_io/checkpoint tests and sequential-runner integration test. Detect changed state names, double-added mHC residual, frame mixing, broken optimizer/LR/RNG/sample continuity. Compare real DPT 10k and d512/l6 checkpoints against the archived source in independent processes, with exact CPU FP32 outputs at saved T.
- CNN variants: unit tests extend `test_x3d_csn.py`. Check legacy IB state/output identity, fixed downsampling and four output scales, actual expanded widths, temporal gradient support (IB/ConvNeXt: 3/6/9/11; FFN tail: 3/3/3/3), and all-stage gradients. Keep irregular asymmetric images and double precision. Add one real-runner DPT save/resume integration case. At most 12 new cases, target <1 second each; integration may exceed 5 seconds to compare actual optimizer checkpoints.
- MSDA: CUDA integration tests compare the unmodified official function against the official PyTorch numerical reference (tests only), including noninteger/edge/outside/padded sample locations and all value/location/weight gradients. Verify all original channel-width gradcheck cases, explicit FP32 under BF16, CPU/invalid shapes/dtype rejection, chunk output/gradient equality. Unit-test configuration, (x,y)/(H,W), level ordering/reference normalization and padding. No runtime reference fallback. Test at most 20 small cases; numerical gradcheck uses fast_mode and records this distinction.
- Training: five real-shape smoke jobs save/resume with independent Drive readback. Data/augmentation draws must be independent of architecture initialization RNG. Stop on failed validation, nonfinite values, OOM beyond the agreed 3-level option, or persistence failure. Full benchmarks/training only from pushed commits.
