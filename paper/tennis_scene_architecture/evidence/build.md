## 再ビルド手順

空の `build/` を用意し、リポジトリのルートで実行する。初稿の統合時刻を `SOURCE_DATE_EPOCH` に指定してPDFの日時を固定し、コミット前後で同じ値を使う。

```bash
set -e
paper=paper/tennis_scene_architecture
SOURCE_DATE_EPOCH=1795817876 TZ=UTC bash "$paper/build.sh" --check-tracked
awk '/Warning|Overfull|Underfull|Missing character:|Rerun to get cross-references right/ {
    print
    count++
}
END {
    printf "reportable diagnostics: %d\n", count
    exit (count > 0)
}' "$paper/build/main.log" "$paper/build/main.blg"
pdfinfo "$paper/build/main.pdf"
sha256sum "$paper/build/main.pdf"
```

追跡入力は `build.sh --check-tracked` で照合し、警告、未解決参照・引用、文字欠落、はみ出しはlatexmk収束後の `main.log` と `main.blg` を確認した。
