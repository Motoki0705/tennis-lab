本システムには、\cref{fig:system}に示す、互いに独立して検証される二つの境界がある。
\emph{シーン境界}は、画像、キャリブレーション済みカメラ、疎なシーン点、
明示的な座標規約、およびレンダリング可能なGaussianモデルからなる公開標準シーン
エクスポートのみを受理する。コートパイプラインは、再構成の内部実装を取り込まず、
暗黙のCOLMAP／チェックポイントの配置を推測しない。\emph{計量境界}は、ライン証拠、
スケール、トポロジー、相互変換、およびホールドアウト残差が型付き品質ゲートを
通過した後にのみ
シーンを受理する。

受理されたシーンは、複数コートのレイアウト
\(
  \mathcal{L}=\{\T{\Scene}{\Court_i},
  \T{\Court_i}{\Scene},\mathcal{B},\mathcal{M}\}_{i=1}^{N_c}
\)
を公開する。ここで、\(\mathcal{B}\)は複合施設の境界を表し、\(\mathcal{M}\)は
フィッティング用およびホールドアウト用の指標を含む。下流のデータセットコードが
この正規情報を再フィッティングまたは
再解釈することは許されない。下流コードは、計量的なカメラ中心をサンプリングし、
対象コートを選択し、OpenCVのcamera-to-scene変換と内部行列を構築し、カメラを
レンダラのシーン単位へ戻した上で、RGB／深度レンダリングを要求する。ラベルは、
同じ不変な変換から計算される。

学習時には、カメラ側エンドの向きに関する曖昧性を除くため、対象コートの
ビューを正準化する。姿勢クエリは、カメラ中心、canonical-from-camera回転、および焦点距離を
予測し、三つの密予測ヘッドは\KPヒートマップ、コートラインマスク、およびコート
セグメンテーションを予測する。直接損失は、すべての出力をそれぞれの正解データへ
固定する。さらに、\cref{sec:consistency}の分岐間損失により、密な座標と姿勢投影が、
同じ拡張済み画像座標系における同一の正準コートを記述することを要求する。
