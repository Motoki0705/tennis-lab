- Dataset metadata validation is centralized in `src/tasks/base/data/court_coordinate_contract.py`; checkpoint validation is centralized in `src/tasks/base/model_io/court_coordinate_contract.py` and the task checkpoint adapters. Direct inspection found one acceptance-breaking bypass: PLCS public scene loading makes validation optional and silently bypasses it when omitted.
