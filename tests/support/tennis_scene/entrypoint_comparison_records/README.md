# Entrypoint comparison evidence

These records were generated by [the comparison driver](../entrypoint_comparison.py):

- [Base versus the initial implementation](base-vs-initial.md).
- [Base versus the callback failure fix](base-vs-callback-fix.md).

Each record pins the source commits actually loaded in two separate Python
processes, verifies every loaded repository module against its Git blob, and
checks 31 cold executions, 31 cache hits and dataset publication. The driver
also writes full source manifests and output snapshots as `base.json`,
`head.json` and `comparison.json` in the requested output directory.

The recorded implementation commit precedes this evidence-only commit. The PR
discussion links an additional run against the final PR HEAD; its `src` tree
and driver must match the implementation recorded here. This avoids treating a
record's containing commit as if it had already been executed.

Only `annotation.generated_at` is excluded from output equality. The fixture
path is reused after deleting the entire preceding run's fixture and store,
so path-dependent identities can be compared exactly without sharing cache.
Host paths are redacted in saved snapshots; IDs and checksums are not rewritten.
