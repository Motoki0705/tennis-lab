# GitHub Wiki 執筆ガイドライン

タイトルの次に、ページで扱うデータ・方式・判断から書き始める。「想定読者」「検索キーワード」「正本ファイル」を並べた冒頭の定型欄、入口への定型戻りリンク、「基準日」の定型ブロックは削除する。主要な導線はサイドバーに集める。出典と正本は関連する本文の近くか末尾の出典節に置き、解釈に必要なデータの版、測定日、判断日はそれぞれの記録に添える。

## 情報の階層

- データセットやファイル配置はディレクトリツリーを使う。まずルートと主要な枝を見せ、ファイル単位の仕様は枝ごとの折りたたみに入れる。
- モデル別の用途・入力・利用条件は、モデルを親にした階層リストにする。判断経緯は日付や決定ごとの見出し・項目に分ける。
- 生成元、派生先、処理順など複数の枝をつなぐ関係は Mermaid で示す。モバイル幅や段数が多い図は `flowchart TD` を基本にする。短い段数で横に並べて見比べたい図には `flowchart LR` を使う。ファイル名や変換契約を本文からも追えるようにする。
- 折りたたみは、開始タグの前、`</summary>` の後、閉じタグの前後に空行を置く。折りたたみ内のリストやコードブロックは開いた状態で表示を確認する。

````markdown
### ファイル仕様

<summary>人物評価の入力ファイル</summary>

```text

  manifest.json
  quality_counts.csv
```

- `manifest.json` に対象範囲と入力の版を記録する。
- `quality_counts.csv` から採点対象と除外の件数を確認できる。

</details>

### 評価方法
````

## Markdown 表を残す条件

2〜4列・おおむね12行以内の平坦な索引、対応表、小規模な同条件比較は Markdown 表を使える。1セル40字程度を目安とし、390px幅の GitHub Wiki で横スクロールなしで行名と値を対応づけられることを確認する。長いコマンド、ファイル仕様、親子関係、判断根拠は、コードブロック、ツリー、折りたたみ、階層リストのうち内容に合う形式に移す。

## 数値表とグラフ

- 正本の CSV／JSON から Typst で数値表、Matplotlib でグラフを生成する。多列の結果は精度、速度と VRAM、batch、workload など目的別に分け、同じ行キーでたどれるようにする。
- 数値表は余白を小さく取り、列見出しに単位、数値に統一した表示桁と右寄せ、関連条件にグループ見出しを使う。最良値の太字と Pareto は丸め前の値で判定する。欠測の記号は `—`、実測ゼロは `0.00` など列の桁で表示する。状態欄や注記に未計測、除外理由、打ち切り、変換異常、実行不能、ロードのみを記す。
- 図の軸に指標と単位を置き、図表に母集団、workload、入出力、batch、計時範囲、同期、VRAM の定義を添える。順位は同じ条件の計測内で決める。診断点は × などの形状やラベルで示し、非比較の理由を値の近くに残す。
- SMPL などに由来する疑似GTは参照の作り方、関与したモデル、採点対象と除外を示す。未ラベル人物の precision／AP や人手の独立GTへの精度は未定義・未測定として扱う。身体復元は定性評価の扱いを明記し、速度と VRAM を定性評価の結論から独立して示す。

## アセットとテキスト参照

生成コード・テンプレート・テスト・執筆規約は本体リポジトリで版管理する。Wiki リポジトリの `assets/<page-slug>/` に画像を置く。ページ slug は小文字の kebab-case にし、ファイル名と同じ stem の相対リンクを使う。名前で指標や必要な batch を区別できるようにする。

白背景・濃い文字・薄い枠線のライト共通1版を使う。日本語をパス化した SVG を表示し、原寸 SVG と互換 PNG のリンクを付ける。 `alt` に何を比較したか、指標と計測条件、近くのテキスト参照先を記す。図表と同じ値・単位・状態のテキスト表を折りたたみに置き、固定版の公開正本もリンクする。

```markdown
![人物検出の速度と VRAM。画像 B1。数値と状態は直下のテキスト表を参照。](assets/person-detector-and-ecpose-comparison/detection-b1-speed.svg)

[SVG 原寸](assets/person-detector-and-ecpose-comparison/detection-b1-speed.svg) · [互換 PNG](assets/person-detector-and-ecpose-comparison/detection-b1-speed.png)
```

- [ ] 正本の値、単位、分母、欠測・除外、順位、疑似GTに関する注記が画像とテキストで一致する。
