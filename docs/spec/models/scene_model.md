# SceneModel アーキテクチャ仕様

本書は、SceneModel（シーンベースの検出・追跡モデル）のアーキテクチャを、レイヤー別に俯瞰できるようにまとめる。

- コード: `src/models/scene_model/*`
- 設定: `configs/models/scene_model.yaml` など
- 学習フロー: `docs/spec/training/scene_model.md` を参照

ここでは **構造と責務** にフォーカスし、実行方法は `docs/spec/cli/scene_model.md` / `docs/spec/scripts/train.md` に委ねる。

---

## 1. 全体像

SceneModel は、おおまかに次のコンポーネントから構成される。

1. **バックボーン**: 入力フレーム列から特徴マップを抽出
2. **ポジショナルエンコーディング**: 2D 空間・時間方向の位置情報を埋め込み
3. **テンポラルモジュール**: 時間方向の依存関係をモデリング
4. **デコーダ**: シーンレベルのクエリに対して、物体ごとの予測を生成
5. **ヘッド**: クラス / バウンディングボックスなど最終出力を整形
6. **ビルド・設定層**: `config` に基づき、各モジュールの組み合わせを構築

---

## 2. バックボーン層

- 役割:
  - 画像フレーム（もしくは前処理済みテンソル）から、空間的な特徴マップを抽出する。
- 実装ポイント:
  - 既存の CNN / Transformer バックボーン（例: ResNet, Swin など）をラップ
  - 出力形状は `[B, T, C, H, W]` または `[B*T, C, H, W]` のいずれかに正規化される

バックボーンの詳細な選択肢はモデル設定 YAML によって切り替えられ、SceneModel 側では抽象インターフェースに依存する。

---

## 3. ポジショナルエンコーディング

- 役割:
  - 2D 空間位置（H, W）と時間軸 T に対する位置情報を特徴に付加する。
- 典型的な設計:
  - 2D CNN 特徴に対するサイン・コサイン型エンコーディング
  - 時間軸に対する 1D エンコーディング
- 出力:
  - バックボーン出力と同じ形状を持つテンソルに、位置埋め込みが加算される。

---

## 4. テンポラルモジュール

- 役割:
  - フレーム間の関連性をモデリングし、過去・未来の文脈を活用して現在フレームの表現を強化する。
- 代表的な実装方針:
  - Transformer ベースの自己注意
  - もしくはシンプルな 1D Conv / RNN など
- 入出力:
  - 入力: `[B, T, N, C]`（N は位置またはクエリ数）
  - 出力: 同形状で、時間方向に依存関係を織り込んだ特徴

---

## 5. デコーダ

- 役割:
  - シーンごとのクエリ（例: オブジェクトスロット）に対して、最終的なオブジェクトごとの特徴を生成する。
- 特徴:
  - DETR 系の設計に倣い、固定数のクエリベクトルを反復的に更新
  - バックボーン＋テンポラル特徴とクロスアテンション
- 出力:
  - オブジェクトごとの潜在表現 `[B, Q, C]`（Q: クエリ数）

---

## 6. ヘッド

- 役割:
  - デコーダ出力から、実際のタスクに対応する予測を計算する。
- 代表的な出力:
  - クラスロジット
  - バウンディングボックス回帰パラメータ
  - 追加の属性（スコア、ID など）
- ロス計算:
  - ヘッドは、マッチング（Hungarian など）とロス関数の選択にも関与することが多い。

---

## 7. ビルドと設定

- 設定ファイル:
  - `configs/models/scene_model.yaml` 等で、バックボーン種別・チャネル数・層数などを指定
- ビルドロジック:
  - `src/models/scene_model/config.py` に近い層で、YAML から Python オブジェクトへの変換を行う
  - SceneModel 本体は、設定オブジェクトを受け取り、各モジュールを組み立てる
