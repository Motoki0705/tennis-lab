# 共享球场的漂移诊断

[English](README.md) · [日本語](README.ja.md)

`inspect_frame(rgb, shared_h, supported_lines, DriftConfig())` 使用共享拟合已确定的H和球场线语义，独立诊断每一帧。不重新估计H、线身份、端点或球网排除带。沿已知直线提取成对白边，测量有符号法向偏移，并拟合平移、旋转、统一缩放四个参数。

两条相交直线无法确定绕交点的缩放，所以初始解需要三条物理线。最终至少需要四条线，其中横线至少一条、纵线至少两条，两个方向夹角至少12度且矩阵秩为4。观测矛盾、多种同等支持的运动、秩不足或不确定性过大均为 `drift_unobservable` 失败，不自动改用平移模型或局部H。

每条物理线仅使用10/90百分位的两个空间锚点，不将像素数当作独立证据数。锚点噪声下限1px和残差决定参数协方差，再传播到可见关键点。投影标准差上限5px、线残差上限3px、搜索半径48px；均按1920×1080的对角线缩放。

平均位移减去两倍标准差超过3px时给出 `camera_moved_possible` 警告；可靠的平均位移超过10px或最大位移超过25px时失败。无法观测也失败。下游始终使用原共享H。

`summarize_clip` 保留所有帧，以失败、警告、正常的顺序取最坏判定。不进行时间平均，也不假设各帧姿态相同。未采样帧没有安全保证。真实的投影运动可能超出四参数模型，因此模型矛盾不能单独证明相机移动或静止。

支持量及不确定性阈值在人工开发集上冻结后再评价。证据见[run 78](../../../../../knowledge/nodes/court_detection/000078-run-court-video-drift-lines-20261117.md)，保存和显式加载见[视频成果物入口](../../../../tennis_scene/pipeline/video_court/README.zh-CN.md)。
