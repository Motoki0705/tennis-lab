
# Refactor: Consolidate Court Schema and Remove Redundant Definitions

## Summary
This PR refactors the court schema definitions to unify `COURT_SKELETON`, `COURT_LINE_CONNECTIONS`, and court dimensions into a single module `src/utils/schema/court.py`. It also renames `src/utils/schema/keypoint_schema.py` to `src/utils/schema/player.py` to better reflect its content (human pose definitions only) and removes `src/utils/geometry/court.py`.

## Changes
- Created `src/utils/schema/court.py`: Contains all court dimensions, keypoint definitions, skeleton connectivity, and normalization scales.
- Renamed `src/utils/schema/keypoint_schema.py` -> `src/utils/schema/player.py`: Removed court definitions, keeping only human pose definitions (COCO-17, SMPL-H).
- Deleted `src/utils/geometry/court.py`.
- Updated all import statements across the codebase to point to the new schema locations.
- Replaced `COURT_LINE_CONNECTIONS` with `COURT_SKELETON` (unified definition).
- Updated `CourtRenderer` and `SkeletonRenderer` to use the new schemas.
- Verified renderers and imports with test scripts.

## Verification
- Validated that `CourtRenderer` produces correct court lines.
- Validated that `SkeletonRenderer` produces correct skeleton connectivity.
- Checked import statements for correctness.
