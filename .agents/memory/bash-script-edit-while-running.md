applies_to: all

---

bashはスクリプトを最初に全部読み込まず、ファイルディスクリプタから1コマンドずつ読む。実行中に同じinodeのまま書き換えると（エディタの上書き保存、Pythonの `write_text` など）、実行中のプロセスは古いバイトオフセットから新しい内容を読み続ける。2026-09-30 には、約40個のlauncherの後半が壊れ、二重実行や異常終了が起きた。

**使い方:**
- 長時間動くシェルスクリプト（launcher、queue worker、watchdog）を編集する前に、実行中のインスタンスがあるかを確かめる。
- 新しい内容は一時ファイルに書いてから `mv` で置き換える（inodeが変わり、実行中のものは古い内容を使い続ける）。
- 長時間動くスクリプトの本体は `main() { ...; }; main "$@"` で包み、実行前に全体がパースされるようにする（`.agents/ops/` のスクリプトはこの形）。
