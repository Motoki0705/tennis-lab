`run_in_background` やMonitorで起動した監視は、その会話のClaude Codeプロセスに属する。プロセスが終わる（端末を閉じる、WSLが落ちる、会話を後で再開する）と、監視も止まる。再開後の会話には、止まったことも、監視していたjobの終了も通知されない。scratchpadの一時ファイルも残らないことがある。

**使い方:** 会話を再開したら、まず走っているはずの監視プロセスが生きているかを確かめる。無ければ、監視対象の状態を直接確認してから張り直す。数日かかるjobを監視するときは、会話を開いたままにする必要があることをユーザーへ伝える。監視スクリプトはscratchpadではなく、消えない場所にも置く。
