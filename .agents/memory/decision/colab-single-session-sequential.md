ユーザーは、複数条件の学習をColabで行うとき、条件ごとにsessionを並列に立てず、L4の1セッションで1本ずつ順に実行することを望む。並列にすると、VMごとにdatasetの取得を繰り返すため。ColabのVMは約12時間で消えるので、保存済みのcheckpointと段階ごとの完了記録から再開する手段が要る。

**使い方:** Colabの複数条件の実行を設計するときは、1セッションでの逐次実行と、新しいVMで同じコマンドを再実行すれば完了済みの段階を飛ばし、途中の学習を同じ条件のcheckpointから再開する手順を最初から含める。並列化を提案するなら、データ取得の重複というコストを明示する。
