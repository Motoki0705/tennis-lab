定期的に起きて進捗を見る待ち方（`ScheduleWakeup` や /loop の tick）は、起きるたびにコンテキスト全体を読み直すため、トークンを大きく消費する。ユーザーは、完了・失敗・プロセス終了のときだけ起きる待ち方を求めている。

**使い方:** ジョブを始めたら、Monitor か background の until ループで、完了・失敗・worker の終了・エラー文字列だけを監視してターンを終える。進捗のポーリングはしない。
