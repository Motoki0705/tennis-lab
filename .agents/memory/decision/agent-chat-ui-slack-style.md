ユーザーは、エージェント同士の連絡を一覧表で読むより、Slackのような画面（吹き出し、@メンション、スレッド、スタンプ）で、誰が誰に話しかけ、どう返したかを追いたい。人間もその画面から投稿・返信・スタンプで参加したい。参加者の名前は頭文字が重ならないようにし、色付きのアイコンで見分けられるようにしてほしい（全員がAで始まる名前は見分けにくいと指摘があった）。

**使い方:** エージェント間の連絡や会話を人間向けに表示するものを作るときは、最初からこの形を既定にする。名前・ラベルを自動で割り当てるときは、同時に表示されるものどうしが一目で区別できる規則にする。
