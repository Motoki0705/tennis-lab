ユーザーは、外部の利用者が読む文書（トップのREADME、導入ガイド、LICENSES、Hugging Faceのcard）で、同じ段落に複数の言語を並べる書き方を嫌う。英語版を既定のファイル名にし、日本語版は `.ja.md`、簡体字中国語版は `.zh-CN.md` に分け、冒頭の English / 日本語 / 简体中文 のリンクで切り替える形を選んだ。中国語は簡体字（zh-CN）のみを対象とし、繁体字版は作らない。

また、文書の表にSHA-256などのハッシュ値を載せると冗長になるので書かない。固定値はコード（preflight・取得CLI）だけに置き、文書には「検査する」と書くにとどめる。同じ表を複数の文書に載せるときは、コードから生成してテストで一致を強制する。

**使い方:** 公開向けの文書を新しく書く・直すときは、英語・日本語・簡体字中国語の3言語を別ファイルでそろえ、以後の更新でも情報を省略せず対応を維持する。文書間リンクは同じ言語版へ向け、言語間で共通の明示アンカーと表マーカーを使う。コマンド・パス・識別子・引用情報・機械可読メタデータは保持し、訳語は同じ言語の文書間で統一する。repo内部の開発者向けREADMEは対象外（日本語のままでよい）。文書にハッシュ値の表を足さない。
