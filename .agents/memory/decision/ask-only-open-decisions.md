人間は同じことを何度も聞かれることと、説明が足りない選択肢を出されることを嫌う。以前の回答で決まる事項を除き、互いに独立した未決事項だけを尋ねる。回答が得られなかった問いを同じ形で繰り返す代わりに、どこが伝わっていないかを確認する。

選択肢には、コードを読まなくても判断できる説明を添える。説明を求められたら、対象や違いを平易な用語と具体例で示してから判断を求める。
