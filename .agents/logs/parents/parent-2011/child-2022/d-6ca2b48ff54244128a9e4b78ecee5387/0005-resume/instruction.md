## API keyの扱い

- keyは `[local path]`（1行、権限600）にあります。探索CLIを実行するコマンドの中だけで、`OPENALEX_API_KEY="$(head -1 [local path])"` として渡してください。
- keyの値、keyを含むURL・ヘッダー・環境変数の一覧を、repo・PR・commit・探索文書・最終報告・ログに出さないでください。`env`、`set -x`、keyを含むコマンドの出力、ヘッダーのdumpは使わないでください。
- `OPENALEX_EMAIL` は引き続き使いません。
- 探索文書には「認証付きのAPI keyで照会した」という事実だけを書いてかまいません。
