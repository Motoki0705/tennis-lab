PR #2044 の実行結果を親が確認しました。WASB深さ2で深さ2へ展開できたのが0本になったのは、データの性質ではなく実装の問題が主因です。同じbranch・PRで次を修正し、WASB「比較対象・深さ2」を再実行してください。

1. 一時的な照会失敗を「未同定」として保存しない（必須）。
   保存済み文書の未同定のうち112行の理由が `reference lookup failed: openalex: HTTP 429` です。レート制限・5xx・通信失敗は文献の性質ではないので、`unresolved` として確定保存し、再実行で読み直さない（既読扱いにする）のは静かなフォールバックにあたります。
   - OpenAlexへの照会に明示的な速度制御と、上限付きの再試行（Retry-After・指数backoff）を入れる。
   - 上限を超えても失敗する場合は、その論文を未完了のまま探索をエラーで止め、同じ条件の再実行で続きから再開できるようにする。
   - `unresolved` は「照会は成功したが一意に同定できなかった」場合だけにする。
   - 既存の保存文書にある一時失敗由来の `unresolved` は、再実行で照会をやり直して置き換える。どの文書を作り直したかをPRに書く。
   - `OPENALEX_EMAIL` などの連絡先は、環境にあれば使ってよいが、文書・ログ・PRに書かない。
2. 同定率を上げる。深さ1の論文（FootAndBall、DeepBall、MonoTrackなど）では、比較対象の行がほぼすべて未同定でした。題名の完全一致検索だけに頼らず、引用元の論文のOpenAlex `referenced_works`（引用元が参照する文献IDの一覧）を候補にして、参考文献行の題名・年・著者と照合する方法を優先してください。誤結合は避け、候補が複数あるか一致しない場合は従来どおり未同定とし、理由を残してください。照合規則のunit testを追加してください。
3. 本文取得失敗（TrackNetV2とBallTrackはDOIの landing page だけ）について、OpenAlexのopen accessの所在（`best_oa_location`、`locations` のPDF URL）など、取得を試みた候補を理由に残してください。取得できないものを無理に取りに行く必要はありません。
4. 修正後に、WASB「比較対象・深さ2」を再実行してください。読解した本数、取得失敗、未同定（理由別）、判定不能の件数と所要時間を、修正前と並べてPR本文に書いてください。時間の上限は合計6時間です。agyかOpenAlexの枠切れが続く場合だけ、そこまでの結果と残りの見積もりをPRに書いて止めてかまいません。
