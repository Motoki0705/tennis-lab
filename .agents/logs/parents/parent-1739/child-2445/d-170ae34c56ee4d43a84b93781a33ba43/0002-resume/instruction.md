# 親からの続き（担当親 Joseph）: 断片の統合（選手枠への割当）

PR #2469 のCIは全件成功した。次は、Meiji 3cam で出た弱点に取り組む。
- 遠側の選手の軌跡が断片化する（fragment 190）。
- そのため選別recallが 61.43% にとどまる（000/000 の正側は最長229 < 必要253フレーム）。

## 方針（親の推奨。ユーザーには説明済み）

時間窓のリンクの後に、2段目として**選手枠への断片の割当**を加える。
- ダブルスは各側2人、シングルスは各側1人（`players_per_side`）で、clipの途中で選手の数は変わらない。
- 次の手順で解く。
  1. 1段目の断片（トラック）から、選手枠の「核」を作る。核は、滞在が長く確度の高い軌跡とする。
  2. 残りの断片を、時間が重ならない範囲で枠へ割り当てる。手がかりは位置・速度の連続性、体格（骨長）、側（y の符号）。割り当てない断片は非選手として扱う。
  3. 割当は全体最適で解く。同じ枠に時間の重なる断片を入れない。
- 選別の判定は、統合後の枠単位の滞在で行う。
- 長い遮蔽（0.4秒超）をまたいでつないだ区間は、統合でつないだことを明示する。具体的には、隙間のフレームを予測・補間として区別し、統合リンクの確信度と曖昧さを保存する。根拠のない連結を実測扱いにしない。
- 判定に使う閾値は、開発用データ（3cam開発用4本・4cam）の統計から決め、根拠を knowledge に残す。holdout 3 clipでは調整しない。
