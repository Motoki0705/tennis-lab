## 修正対象（全 3 件）

### 1. Wiki に転記した数値・状態・画像の誤りを検出できるようにする
- **指摘内容**:
  固定版正本から生成した Methods のスニペットで画像数を `6,844` から `6,845` に変え、`verify --output <bundle> --wiki-page <page.md>` を実行すると終了コード 0 になった。`tools/wiki_assets/__main__.py` の `_verify` は生成バンドルと Wiki 実ファイルを独立に検査するため、両方を指定しても転記した数値・状態・画像の一致を確認できない。
- **対応要件**:
  - `verify` で生成バンドル（`--output`）と Wiki 実ファイル（`--wiki-page`）がともに指定されたとき（またはページ slug が対応するとき）、Wiki 実ページ内に取り込まれた各アセット画像（SVG・PNG）の SHA-256 が検証済みバンドルの出力画像と完全一致することを検証する。
  - さらに、Wiki 実ページ内に取り込まれた折りたたみテキスト表／生成済み埋め込み節（数値・単位・状態・行内容）が、検証済みバンドルで生成された正規テキストと完全一致することを検証し、たとえば `6,844` → `6,845` のような 1 桁の転記誤り・行欠落・状態改変・画像差し替えを確実に非ゼロ終了で拒否する。
  - 複数の節を持つページや、手書きの本文中に複数の生成スニペットを埋め込んだ実 Wiki ページ（後続の人物モデル比較 5 ページ改訂で実際に使う形式）でも曖昧さなく確実に照合できる契約を設計し、`tools/wiki_assets/README.md` に検証の使い方を明記する（例: 生成スニペットのマーカーまたは対象ページ slug の各セクション・`<details>` ブロックとバンドルの照合）。
  - 数値 1 箇所を改変したケース・画像を差し替えたケースで確実に失敗し、正常転記では成功する回帰テストを追加する。

### 2. Wiki が直接参照する PNG の実体を検査する
- **指摘内容**:
  PNG だけを相対参照する Wiki ページを `verify --wiki-page` に渡すと、画像の内容を検査せず終了コード 0 を返した。`tools/wiki_assets/markdown.py` の `verify_markdown` が返すのは SVG だけで、CLI はその対になる PNG しか検査しない。
- **対応要件**:
  - `verify_markdown` が相対参照されるすべての PNG（SVG の対になっているものだけでなく、Markdown 画像・リンク・HTML `<img>` 等で直接参照される PNG も含む）を漏れなく収集・返却し、CLI（および検証関数）がすべての参照 PNG に対してサイズ上限・RGB・必須チャンク・不要メタデータなしの検査を適用する。
  - PNG だけを直接参照する正常ページは通過し、破損・非RGB・サイズ超過・不要テキストチャンク混入等の不正 PNG を直接参照するページは確実に拒否する回帰テストを追加する。

### 3. 公開禁止情報の検査で一般的なローカル絶対パスと UNC パスを拒否する
- **指摘内容**:
  `tools/wiki_assets/publication.py` の `scan_public_text` に `[local path]` と Windows の UNC 共有パスを渡すと通過した。現在の検査は列挙したディレクトリ名とドライブ文字などに限られ、端末固有の絶対パスを見逃す。
- **対応要件**:
  - 既存の `.agents/ops/board/safety.py` の絶対パス判定実装を参照し、公開 URL（`https://...`, `http://...`）・Wiki 相対パス・リポジトリ相対パス・Markdown 記法・コード中の正規表現や単位表記（例: `ms/画像`, `人/秒`, `6,844/46,228`）を誤検知せず保持しつつ、**任意の POSIX ルート直下の絶対パス**（例: `[local path]`, `[local path]`, `[local path]`, `[local path]`, `[local path]`, `[local path]` 等）と **Windows ドライブパスおよび UNC 共有パス**（例: `[local path]`, `[local path]`）を確実に拒否する。
  - `[local path]`、Windows UNC 共有パス、POSIX 一般絶対パスが拒否され、公開 URL・リポジトリ相対パス・単位スラッシュ・実正本から生成された全 5 ページのスニペットや `docs/wiki/*.md` が誤検知なしで通過することを検証する回帰テストを追加する。
