# 対象外と作業制約

- 今回含めない機能・変更: <隣接タスクとの境界>
- このworktreeの外は変更しない。メインtree、共有 `.venv`、`data/`・`ckpt/` 等の
  symlink先を変更しない。依存のインストールや環境更新をしない。
- 他の担当の変更を上書き・revertしない。許可範囲の拡張が必要なら、編集せず未解決点として返す。
- **git commit / push、ghによる書き込み（issue/PR/comment/label等）、merge、外部サービスへの
  書き込みをしない。** 取り込みは親が行う。
- **dshの再帰呼び出し・再委譲をしない。deepseek-harness skillは親専用なので使用しない。**
  再帰拒否を回避するために環境変数を解除しない。
- キーや資格情報を作成・探索・読み取り・表示・転記しない。設定不足は親へ返す。
- GPU処理・学習・描画を起動しない。未確定のデータや素材、仕様を独断で選定しない。
- 静かなフォールバックで欠測・失敗を成功へ変えない。前提不足や人間の判断が必要なら止めて報告する。

# 実行すべきテストコマンド

worktreeのrootで実行する。Pythonは `.venv/bin/python` を使い、pytestは `-n 4` 以下、
同時に1プロセスだけとする。次の欄を実際に実行できるコマンドへ置き換える。

```bash
<今回の新規/変更部分を確認するCPUテスト>
<影響する既存の回帰テスト>
```

実行不能・失敗・skipは、コマンドと理由を記録し、成功扱いしない。

# 出力形式

最終回答は次の3項目を箇条書きで返す。

- 変更ファイル一覧: 各パスと変更した挙動。
- 実行したテストと結果: コマンド、終了値、pass/fail/skip。未実行なら理由。
- 未解決点: 残る不具合・前提不足・親への判断依頼。なければ「なし」。
