# issueの進捗を説明する

引数のissue番号について、いま何が起きているかを調べて人間に説明する。
説明はできるだけ直感的にわかりやすいように記述する。
複数ターンで人間が理解を深めていけるようにする。
まとめて一気に全部を説明しようとしない。

## 含める内容
1. 最初に親AIが取り組んでいる内容や目的について、親issueなどを調査して説明する。
2. このissueが完了したらどうなるのかを含める。
3. 全体像の中で、現在は何をしているかを説明する。
4. 今後は何をしていく予定化について説明する。
5. 何が完了したらタスク全体が終了なのかを調査して、説明する。
6. あとどのくらいで完了しそうかについて説明する。
